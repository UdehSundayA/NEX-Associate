PART 3: THE 6-AGENT AI ECOSYSTEM
The Golden Rule
[!IMPORTANT] NEX Curriculum decides what is taught. NEX Associate tells the human teacher how to teach it in class. NEX Tutor reinforces it online with the student. NEX Quizzer tests it competitively. NEX Finance handles the money. NEX Care protects the user experience. All six serve the same curriculum autonomously.
3.1 Agent 1: NEX Curriculum (The Architect)
The foundational authority that integrates Nigerian, Ghanaian, British, and American standards. Updates annually based on examination body syllabus changes.
3.2 Agent 2: NEX Tutor (The Student AI)
Delivers 1-on-1 tutoring using a highly structured 4-Phase Workflow: 1. Phase 1: Real-Time Vision & Voice: Uses Stream Vision SDK. Student turns on camera; AI sees handwritten work and teaches via voice. 2. Phase 2: Q&A Chat: Text-based Socratic questioning. 3. Phase 3: Flashcard Summary: Auto-generates high-yield HTML/PDF flashcards. 4. Phase 4: CBT Assessment: Generates 10 MCQs, auto-scores, and reports to database.
3.3 Agent 3: NEX Associate (The Teacher AI)
Runs on the Teacher Dashboard, generating weekly delivery packages (via Email/WhatsApp): - Monday (7 AM): Formal 5-column Lesson Plans. - Sunday (6 PM): Detailed Notes of Lesson (objectives, hooks, step-by-step development). - Friday (5 PM): Print-ready Tests & Exams (40-question customized tests) with full marking schemes.
3.4 Agent 4: NEX Quizzer (The Competition Setter)
Generates elite, calibrated question papers. - Levels: State (Challenging), National (Hard), International (Olympiad-style). - Modes: Admin-set competitions, Student Practice Mode, Live Multiplayer Competitions.
3.5 Agent 5: NEX Finance (The Money Manager)
Autonomous billing operations powered by Stripe. Handles subscriptions, bulk school invoicing, and dunning (smart retries).
3.6 Agent 6: NEX Care (Customer Relations)
Handles 24/7 support. Resolves tickets, sends satisfaction surveys, and re-engages inactive users flagged by NEX Finance to prevent churn.

Harmonization: One unified framework across WAEC, NECO, JAMB, IGCSE, SAT.
